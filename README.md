# 🛒 FreshCart — E-commerce Store

**A responsive e-commerce storefront built with React and Tailwind CSS.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-fresh--cart--store--app.vercel.app-16A34A?style=for-the-badge&logo=vercel&logoColor=white)](https://fresh-cart-store-app.vercel.app/)

</div>

## ✨ Features

- 🛍 Product catalog with images and prices
- 🛒 Interactive cart — add, remove and update quantities
- 📱 Fully responsive, mobile-friendly UI

## 🛠 Tech Stack

| Area | Technology |
|---|---|
| Frontend | React · Vite |
| Styling | Tailwind CSS |
| Deployment | Vercel |

## 🚀 Getting Started

```bash
npm install
npm run dev
```
